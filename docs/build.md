# Building

## Requirements

| Tool | Verified version |
|---|---|
| Ubuntu | 24.04 LTS (x86_64) |
| GCC | 13.3 (C++20) |
| CMake | ≥ 3.21 (3.28 used) |
| Ninja | 1.11 (optional) |
| Qt | 6.8.8 at `~/Qt/6.8.8/gcc_64` with Qt Quick Controls (FluentWinUI3), Qt DBus, Qt Svg, Qt Concurrent, Qt Network, Qt Test |
| Docker | for system tests only |

Ubuntu 24.04's own Qt is 6.4 and lacks FluentWinUI3, so the SDK Qt is used and bundled.

## Configure and build

```bash
cmake -S . -B build -G Ninja \
      -DCMAKE_PREFIX_PATH=$HOME/Qt/6.8.8/gcc_64 \
      -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

Options: `-DURDM_BUILD_GUI=OFF`, `-DURDM_BUILD_HELPER=OFF`, `-DURDM_BUILD_TESTS=OFF`.
The install prefix defaults to `/opt/ubuntu-rdp-manager`.

All targets compile with `-Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wold-style-cast …`,
`QT_NO_CAST_FROM_ASCII`, `QT_DISABLE_DEPRECATED_UP_TO=0x060800`, plus hardening
(`-fstack-protector-strong`, `-D_FORTIFY_SOURCE=3`, full RELRO, PIE). The build is warning-free.

## Running from the build tree

```bash
./build/src/app/ubuntu-rdp-manager                       # normal start
./build/src/app/ubuntu-rdp-manager --smoke-test          # visit every page, exit 0 if no QML warnings
./build/src/app/ubuntu-rdp-manager --page 3 --theme dark --size 1366x768 --screenshot out.png
```

Without the helper installed the application shows real status but disables changes.

## Package

```bash
cd build && cpack -G DEB          # → ubuntu-rdp-manager_1.0.0_amd64.deb (~39 MB)
```

The package bundles the Qt runtime (via `qt_generate_deploy_qml_app_script`, plus the gtk3
platform-theme plugin). `Depends:` comes from `packaging/debian/runtime-depends.txt`, which was
generated by running `ldd` on every bundled library/plugin in a pristine `ubuntu:24.04`
container; installing exactly that list leaves no unresolved library.

To produce a different version for upgrade testing: `cpack -G DEB -D CPACK_PACKAGE_VERSION=1.0.1`.

## Helper development notes

* `urdm-helper` refuses to run unless `euid == 0` and only registers on the system bus.
* Its RPATH is the absolute `/opt/ubuntu-rdp-manager/lib` (never `$ORIGIN`).
* To try a modified helper safely, use the disposable server container
  (`tests/system/start-test-server.sh <pki> <stage>`), never the development host.
